# Diseno

Identidad sobria, deportiva y adulta. La paleta combina fondo claro u oscuro con acentos terracota y verde grisaceo para evitar una estetica agresiva de gimnasio.

## Principios

- Jerarquia clara.
- Tarjetas limpias.
- Contraste suficiente.
- Navegacion inferior con cinco destinos.
- Acciones destructivas con confirmacion.
- Texto legible y compatible con escalado de fuente.

## Recursos

El icono adaptativo es vectorial y original. No se usan fotografias de terceros.
