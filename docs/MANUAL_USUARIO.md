# Manual de usuario

## Primer uso

Lee el onboarding, revisa seguridad, elige tema y decide si quieres recordatorios locales.

## Hoy

Consulta el dia actual, calentamiento, entrenamiento, vuelta a la calma y recomendacion nutricional. Puedes iniciar la sesion guiada o marcar el dia como completado.

## Programa

Revisa cualquier dia del programa. El contenido no esta bloqueado artificialmente.

## Nutricion

Consulta objetivo de proteina, estructura diaria, menus, alimentos prioritarios, eliminados y ajustes.

## Progreso

Registra voluntariamente controles en dias 1, 8, 15, 22 y 30. Puedes introducir hasta tres pesos para calcular la media.

## Mas

Consulta reglas, seguridad, privacidad y reinicio del programa. Las acciones destructivas piden confirmacion.
